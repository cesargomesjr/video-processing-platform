# Definition of Done

Uma tarefa só está concluída quando:

- requisito respeitado;
- critério de aceite satisfeito;
- architecture boundaries preservados;
- regra de domínio explícita;
- código legível;
- comportamento novo coberto;
- coverage >= 80%;
- lint passa;
- typecheck passa;
- testes passam;
- build passa;
- segurança considerada;
- concorrência/idempotência consideradas quando aplicável;
- documentação atualizada;
- sem refactor não relacionado.
