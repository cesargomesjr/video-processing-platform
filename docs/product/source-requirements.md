# Requisitos-base do desafio

Este projeto foi estruturado a partir do enunciado do Hackathon.

Requisitos-base considerados:

- processar mais de um vídeo simultaneamente;
- não perder requisições em picos;
- proteção por usuário e senha;
- listagem de status dos vídeos do usuário;
- notificação em caso de erro;
- persistência;
- arquitetura escalável;
- GitHub;
- testes;
- CI/CD.

A arquitetura de chunking, fan-out/fan-in, signed URLs, Clean Architecture, bounded contexts, observabilidade, idempotência e demais decisões são propostas de implementação para atender e elevar esses requisitos.
